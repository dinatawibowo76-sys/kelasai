Persamaan kuadrat adalah persamaan polinomial berderajat dua. Bentuk umum persamaan kuadrat adalah ax² + bx + c = 0, dimana a, b, dan c adalah konstanta dengan a ≠ 0. Nilai a disebut koefisien dari x², b disebut koefisien dari x, dan c disebut konstanta. Cara menyelesaikan persamaan kuadrat: 1) Metode faktorisasi: mencari faktor-faktor dari persamaan. 2) Metode melengkapkan kuadrat sempurna. 3) Rumus ABC: x = (-b ± √(b²-4ac)) / 2a. Diskriminan D = b²-4ac menentukan jenis akar. Jika D > 0, ada dua akar real berbeda. Jika D = 0, ada satu akar real kembar. Jika D < 0, tidak ada akar real. Contoh: x² - 5x + 6 = 0 dapat difaktorkan menjadi (x-2)(x-3) = 0, sehingga x = 2 atau x = 3.
